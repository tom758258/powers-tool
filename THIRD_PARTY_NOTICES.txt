Rebuild the Windows application with a modified zeroconf
-------------------------------------------------------
On Windows x64, use Python 3.13 and Node.js 22 (the GitHub Actions toolchain).

1. Obtain the Powers Tool source matching the distributed version and the
   corresponding zeroconf 0.151.5 source from the URL above. Build your
   modified zeroconf as a Windows-compatible wheel, keeping its package
   metadata version at 0.151.5 so the notices and version check stay correct.
2. In the Powers Tool source root, create or sync the locked environment:

       uv sync --python 3.13 --all-extras --locked --link-mode=copy

3. Replace the zeroconf installed in that environment with your modified wheel:

       uv pip install --python .venv/Scripts/python.exe --no-deps --reinstall <MODIFIED_ZEROCONF_WHEEL>

4. Rebuild the Windows release using the installed replacement:

       powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./scripts/build_release.ps1

   Do not run "uv sync" between steps 3 and 4, or the locked dependency may
   replace the modified wheel. The rebuilt release will contain your modified
   library. The rebuilt distribution is not the official Powers Tool release.
